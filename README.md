# Portfolio Lofi - Benevanio Santos

Projeto de portfólio desenvolvido com HTML, CSS e JavaScript Vanilla, utilizando efeitos 3D com Vanilla Tilt e layout totalmente responsivo.

## Minha História

Este repositório representa muito mais do que um simples projeto de portfólio.

Quando comecei a estudar programação, minha rotina era bem diferente da que tenho hoje. Eu trabalhava no Supermercado Paulistão, saía do Jardim Picerno e seguia para o centro de Nova Odessa todos os dias. Muitas vezes meu expediente começava às 11h e terminava às 22h. Em alguns períodos, também trabalhei no turno da noite, entrando às 21h e saindo às 06h da manhã.

Mesmo depois de jornadas longas e cansativas, eu continuava estudando. Frequentava cursos na Microlins, fazia minha graduação e passava horas praticando programação. Foi durante essa fase que comecei a construir meus primeiros projetos e a acreditar que poderia mudar minha trajetória profissional através da tecnologia.

Este portfólio nasceu desse período da minha vida. Cada linha de código representa noites de estudo, finais de semana dedicados ao aprendizado e a determinação de construir uma carreira como desenvolvedor de software.

Hoje, anos depois, atuo profissionalmente na área de tecnologia, desenvolvendo APIs, integrações, microsserviços e aplicações utilizadas por milhares de usuários. Ainda assim, mantenho este projeto porque ele simboliza o início da minha jornada.

Se você está começando agora, saiba que grandes carreiras normalmente começam exatamente assim: com pequenos projetos, muita disciplina e a decisão de continuar aprendendo todos os dias.

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

## Arquitetura

* `index.html`: estrutura principal da aplicação.
* `assets/css/style.css`: estilização e responsividade.
* `assets/js/main.js`: animações e interações.
* `assets/js/vanilla-tilt.js`: efeito 3D dos cartões.
* `assets/images/`: imagens utilizadas no projeto.

## Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
